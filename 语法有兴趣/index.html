表达兴趣

Как сказать «интересоваться чем-то» по-китайски

1. Базовые конструкции

对……感兴趣
对……有兴趣
对象 = тема интереса: 汉语、电影、音乐、运动、历史、打篮球。
我对汉语感兴趣。
他对电影感兴趣。
同学们对汉语有兴趣。

2. Отрицание

不
对……不感兴趣
我对篮球不感兴趣。
没有
对……没有兴趣
她对音乐没有兴趣。

3. Вопросы

吗

你 + 对 + 对象 + 感兴趣吗？
你对音乐感兴趣吗？
你对汉语有兴趣吗？

什么

你 + 对 + 什么 + 感兴趣？
你对什么感兴趣？
你对什么运动感兴趣？

4. Наречия степени

对……很 / 非常 / 更感兴趣
对……很 / 非常 / 更有兴趣
很
我对汉语很感兴趣。
非常
他对历史非常有兴趣。
更
我对她更感兴趣。
✘ 我很对汉语感兴趣。
✓ 我对汉语很感兴趣。
